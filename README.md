## 📌 Project Overview

**BudgetMate** is a modern, intuitive expense tracking application that helps you manage personal and group expenses effortlessly. Whether you're splitting bills with friends, tracking household expenses, or managing trip costs, BudgetMate provides real-time synchronization, smart settlements, and a beautiful user experience across all devices.

---

## 🚀 Features

### 🔹 Core Functionality
- **Personal Expense Tracking**: Categorize and monitor individual spending
- **Group Expense Management**: Create groups and split expenses automatically
- **Smart Settlements**: Automatic calculation of who owes whom
- **Real-time Synchronization**: Live updates across all connected devices
- **Comprehensive Dashboard**: Overview of financial health and spending patterns

### 🔹 User Experience
- **Dark/Light Mode**: Toggle between themes with persistent preferences
- **Responsive Design**: Optimized for desktop, tablet, and mobile
- **Smooth Animations**: Enhanced UX with Framer Motion
- **Instant Notifications**: Real-time alerts for invitations and updates

### 🔹 Advanced Features
- **Expense Filtering**: Search and filter by category, date, and groups
- **Data Export**: Download expense data for external analysis
- **Profile Management**: Customizable user profiles with avatars
- **Secure Authentication**: JWT-based protected routes

---

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Framer Motion
- **Real-time**: SignalR for live updates
- **HTTP Client**: Axios for API communication
- **Icons**: Lucide React
- **Notifications**: React Hot Toast
- **Routing**: React Router DOM

### 🔑 Authentication & Onboarding

- Profile setup with avatar upload capability
- Instant dashboard access after authentication

### 📊 Dashboard Overview
- **Total Expenses**: Complete spending overview
- **Monthly Analytics**: Current month expense tracking

- **Create Groups**: Set up expense-sharing groups with descriptions
